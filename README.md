# Lacanian Clock

一个单 HTML 的拉康派精神分析主题数字时钟。页面保留纯静态、可直接打开的形式，把原本的极简时钟改成“逻辑时间 / 能指链 / RSI 三界”的视觉主题。

## 功能特性

- **实时时钟** - 显示时:分:秒，使用更接近书页和分析室笔记的衬线字体
- **拉康主题话语** - 打字机式循环输入和删除，围绕欲望、缺失、镜像阶段、能指链和 RSI
- **RSI 视觉层** - 背景网格和 Real / Symbolic / Imaginary 标签
- **觉心词典能指链** - 底部漂移词语链接到觉心论坛词典条目
- **深色模式** - 支持浅色纸面和深色黑板两套主题
- **分析设置** - 可自定义时间、话语、注释字号，调整位置、视差强度和能指链开关

## 使用方法

1. 直接在浏览器中打开 `index.html`
2. 点击右上角按钮切换深色/浅色模式
3. 点击右下角齿轮图标打开分析设置
4. 在设置中可以：
   - 调整时间、话语和注释的字体大小
   - 调整内容垂直位置
   - 调节视差强度
   - 开启/关闭觉心词典能指链

## 发布到 Wallpaper Engine

1. 打开 Wallpaper Engine 编辑器
2. 将 `index.html` 拖入编辑器
3. 设置背景色为透明
4. 保存并发布

## 技术栈

- 纯 HTML/CSS/JavaScript
- CSS Custom Properties 主题系统
- Canvas 动画
- requestAnimationFrame 流畅动画
